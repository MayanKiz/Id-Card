# Lanyard 3D

A standalone interactive 3D lanyard landing page built with Next.js, React Three Fiber, Drei, and Three.js. Ready to import into Vercel.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy to Vercel

Import this repository into Vercel and keep the default Next.js settings. No environment variables are required.

## Notes

- This starter uses a procedural 3D ID card and strap, so it does not require external model assets.
- The card is a placeholder design. Replace its face with your own image or branding when ready.
- This is a custom lightweight implementation, not the original React Bits Lanyard source.
